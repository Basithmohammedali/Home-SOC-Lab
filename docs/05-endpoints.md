# Endpoints

## Purpose

This document explains how Windows and Ubuntu endpoints were configured in the Home SOC Lab. These systems generate telemetry that is collected by Elastic Agent and analyzed using Elastic Security.

---

# Prerequisites

Before configuring the endpoints, ensure that:

- Fleet Server is running.
- Elasticsearch and Kibana are operational.
- Fleet is configured in Kibana.
- Network connectivity is available.
- Enrollment tokens have been created.

---

# Endpoint Overview

| Endpoint | Operating System | Purpose |
|-----------|------------------|---------|
| Windows Endpoint | Windows 11 | Generate Windows Security Events |
| Ubuntu Endpoint | Ubuntu Desktop | Generate Linux Events |

---

# Windows Endpoint Configuration

The Windows endpoint is used to simulate user activity and attacker techniques.

Install:

- Sysmon
- Elastic Agent

Join the endpoint to Fleet using the enrollment command generated by Kibana.

---

# Ubuntu Endpoint Configuration

Install Elastic Agent using the enrollment command generated by Kibana.

Verify that the endpoint successfully connects to Fleet.

---

# Verify Endpoint Status

Open Kibana.

```
Management → Fleet → Agents
```

Verify that:

- Windows Endpoint is Healthy.
- Ubuntu Endpoint is Healthy.

---

# Verify Telemetry

Open:

```
Security → Hosts
```

Confirm that both endpoints are sending telemetry.

---

# Troubleshooting

### Endpoint Offline

- Verify network connectivity.
- Verify Elastic Agent is running.
- Verify the enrollment token.

### Elastic Agent Status

Linux:

```bash
sudo systemctl status elastic-agent
```

Windows (PowerShell):

```powershell
Get-Service Elastic-Agent
```
