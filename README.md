# Home SOC Lab

![Home SOC Lab Architecture](docs/images/lab-architecture.png)

A complete Home Security Operations Center (SOC) Lab built using VirtualBox and the Elastic Stack.

## Overview

This project demonstrates how to build a complete SOC lab from scratch, simulate real-world attacks, create detection rules, and automate incident response using open-source tools.

## Lab Components

- Elasticsearch
- Kibana
- Fleet Server
- Windows Server (Active Directory)
- Ubuntu Endpoint
- Sysmon
- Elastic Agent
- Mythic C2
- osTicket
- Kali Linux
